# WaveSentinel Phase H Backend Bridge

This is the first Python backend for the existing React/Vite UI.

## Scope

- FastAPI local API on `127.0.0.1:8000`
- TensorRT FP32 inference using the frozen Phase G2 engine
- Class-wise frozen thresholds
- Upload Scan inference
- In-memory detection archive
- Mission action endpoints
- System/model contract endpoints
- Explicit simulation / provenance metadata

## Install

Use the existing `D:\debris_envs\debris` environment.

```cmd
python -m pip install -r requirements.txt
```

TensorRT, CUDA and PyTorch are expected to already exist in that environment.

## Run

From `backend`:

```cmd
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

Default engine path:

`K:\Debris model\runs\phase_g2_tensorrt\best_fp32.engine`

Override with `WAVESENTINEL_TRT_ENGINE`.

## API

`GET /api/health`

`GET /api/state`

`GET /api/system/status`

`GET /api/model/contracts`

`POST /api/inference/image`

`POST /api/detections`

`POST /api/detections/{frame_id}/review`

`POST /api/mission/start`

`POST /api/mission/pause`

`POST /api/mission/resume`

`POST /api/mission/end`

`POST /api/settings/reset`

## Important boundaries

Risk is not generated by the detector. Actual uploaded detections are returned as `UNASSESSED`.

Uploaded files are not treated as real hardware telemetry.

Target georeferencing is not invented from image pixels. Position is `not_available` unless supplied by a validated upstream navigation/geometry contract.
